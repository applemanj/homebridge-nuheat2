# 1.2.23 Release Notes

Released: 2026-07-08

## Summary

`1.2.23` fixes the Nuheat Conductor/NAM OAuth handoff introduced by Nuheat's updated identity pages.

## Highlights

- Follows Nuheat's browser-style login and consent redirects before exchanging the PKCE authorization code
- Preserves consent cookies through the final OAuth callback
- Selects the real login and consent forms when the identity page includes multiple forms
- Adds regression tests for the updated OAuth login and consent flow

## Upgrade Notes

- Existing Homebridge configurations continue to work unchanged
- Restart Homebridge after installing so the plugin reconnects and acquires a fresh Nuheat token
