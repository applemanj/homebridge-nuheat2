# 1.2.18 Release Notes

Released: 2026-04-29

## Summary

`1.2.18` simplifies the Homebridge admin UI now that Nuheat provides a built-in PKCE public client for this plugin.

## Highlights

- Removes the Advanced OAuth panel from the custom admin UI
- Removes Advanced OAuth fields from the Homebridge config schema and README
- Removes the editable Platform Name field from the custom admin UI
- Keeps legacy config keys supported at runtime for backward compatibility
- Makes saved thermostat and group allow-list rows easier to see and edit

## Upgrade Notes

- No configuration changes are required
- MyNuheat email and password remain the only account fields most users need
- The plugin continues to use the built-in Nuheat PKCE public client automatically
