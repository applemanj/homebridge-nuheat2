# 1.2.10 Release Notes

Released: 2026-04-21

## Summary

`1.2.10` is a testing-focused patch release for the new official Nuheat OAuth client credentials.

## Highlights

- Requests the full issued Nuheat scope set: `openapi openid profile offline_access`
- Adds targeted OAuth debug logging around configured client ID, requested scopes, consent handling, granted scopes, and refresh-token rotation
- Keeps the logging non-sensitive so client secrets and tokens are not written to the logs

## Upgrade Notes

- No Homebridge configuration changes are required beyond setting your local `clientId`, `clientSecret`, and `redirectUri`
- Enable `debug` if you want to see the new OAuth tracing during live testing
