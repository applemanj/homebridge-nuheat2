# 1.2.5 Release Notes

Released: 2026-04-11

## Summary

`1.2.5` is a small maintenance release focused on code cleanup and test hygiene after the `1.2.4` stable release.

## Highlights

- Simplified accessory setup code paths to reduce repeated lookups
- Consolidated shared Homebridge test stubs into reusable helpers
- Tightened the test script so only `*.test.js` files are executed
- Improved a small amount of logging readability

## Upgrade Notes

- No configuration changes are required
- Existing `platform: "NuHeat"` configuration remains valid
- This release is intended as a drop-in upgrade from `1.2.4`
