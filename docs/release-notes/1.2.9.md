# 1.2.9 Release Notes

Released: 2026-04-15

## Summary

`1.2.9` is a verification-focused patch release that removes the published `homebridge` peer dependency so the Homebridge verification install no longer pulls in `homebridge` and `hap-nodejs`.

## Highlights

- Removed the published `peerDependencies.homebridge` entry from `package.json`
- Kept the supported Homebridge range in `engines.homebridge`
- Preserved the plugin runtime and configuration behavior

## Upgrade Notes

- No Homebridge configuration changes are required
- No plugin runtime behavior changed
- This release is intended to clear the remaining dependency-install failures in the Homebridge verification checks
