# 1.2.25 Release Notes

Released: 2026-07-09

## Summary

`1.2.25` restores Away Mode switches when all Nuheat groups are selected in the plugin settings.

## Highlights

- Makes “Expose away-mode switches for all groups” take precedence over the optional group allow-list
- Supports string group identifiers returned by Nuheat's current Conductor/NAM API
- Updates `ws` to 7.5.11 to address a memory-exhaustion denial-of-service advisory

## Upgrade Notes

- Existing Homebridge configurations remain compatible
- Restart Homebridge after installing so group accessories are rediscovered
- If an Away Mode switch is still absent, verify the Nuheat group exists and remove the cached accessory in Homebridge before restarting
