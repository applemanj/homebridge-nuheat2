# 1.2.8 Release Notes

Released: 2026-04-15

## Summary

`1.2.8` is a verification-focused patch release that fixes the plugin config schema so it conforms to JSON Schema requirements used by the Homebridge plugin checks.

## Highlights

- Replaced field-level `required: true` flags in `config.schema.json` with object-level `required` arrays
- Preserved the same required settings for `name`, `email`, `password`, `devices[].serialNumber`, and `groups[].groupName`

## Upgrade Notes

- No Homebridge runtime behavior changed
- No configuration changes are required for existing users
- This release is intended to clear the remaining config schema validation failure in the Homebridge verification checks
