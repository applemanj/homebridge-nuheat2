# 1.2.15 Release Notes

Released: 2026-04-27

## Summary

`1.2.15` corrects the custom Homebridge admin UI styling regression from `1.2.14`.

## Highlights

- Restores a Homebridge-like system font stack inside the custom UI iframe
- Restyles inputs and buttons so they no longer fall back to browser-default serif/white controls
- Keeps the theme-compatible direction by using inherited text colors and translucent surfaces instead of forcing a separate dark theme

## Upgrade Notes

- No configuration changes are required
- Existing `platform: "NuHeat"` configurations continue to work
- This release only changes the custom Homebridge settings UI styling
