# 1.5.0

Fixes a config-handling footgun reported from 1.4.0 testing.

## Fixed

- **Hold Length of `0` no longer becomes a permanent hold.** An explicitly configured Hold Length of `0` was previously coerced to the 1440-minute default via a falsy fallback, and 1440 is deliberately sent as a *permanent* Nuheat hold — so every manual setpoint change landed as mode 3 (permanent hold) instead of a temporary hold. `0` (or a negative value) is now refused at startup with a logged warning and falls back to the default; values above 1440 are clamped as before. The Homebridge config UI schema now enforces a minimum of 1 minute.

## Upgrade notes

- If you intentionally configured `Hold Length = 0` expecting temporary holds, set it to a real duration (e.g. `180` for a 3-hour hold) and re-test a manual setpoint change from the Home app.
