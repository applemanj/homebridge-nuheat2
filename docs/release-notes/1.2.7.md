# 1.2.7 Release Notes

Released: 2026-04-15

## Summary

`1.2.7` is a maintenance release that starts the plugin's TypeScript migration and adds GitHub Actions automation for CI and npm publishing.

## Highlights

- Moved the core platform, API client, accessories, internal models, and tests to TypeScript source under `src/`
- Kept the published CommonJS runtime layout stable by compiling back into `index.js`, `lib/`, and `test/`
- Added CI coverage on GitHub Actions across Node 20, 22, and 24
- Added automated npm publishing from GitHub Actions when a new package version is pushed to `master`
- Updated package metadata for npm trusted publishing and provenance

## Upgrade Notes

- No Homebridge configuration changes are required
- Existing `platform: "NuHeat"` configuration remains valid
- Future npm releases can now be published automatically by bumping `package.json` and pushing `master`
