# 1.2.11 Release Notes

Released: 2026-04-21

## Summary

`1.2.11` is a small UI-focused patch release that improves the Homebridge Config UI experience for optional device and group lists.

## Highlights

- Removes item-level required validation from the optional `devices` and `groups` arrays in `config.schema.json`
- Adds descriptions that make it clearer those lists are optional allow-lists
- Ignores blank `devices` rows at runtime so accidental empty entries do not block thermostat auto-discovery

## Upgrade Notes

- No Homebridge configuration changes are required
- Existing device and group allow-lists continue to work
- This release is intended to stop the Config UI from surfacing validation errors unless you intentionally fill in those optional rows
