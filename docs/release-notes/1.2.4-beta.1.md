# 1.2.4-beta.1 Release Notes

Released: 2026-04-11

## Summary

`1.2.4-beta.1` builds on the initial modernization beta by aligning more of the plugin with Nuheat's published Swagger schema.

## Highlights

- Added Swagger-aligned internal model normalization helpers
- Added optional per-thermostat schedule switches
- Added account, schedule, and energy log API helpers for future UI and automation work
- Simplified thermostat operating-mode handling to the currently documented Nuheat model
- Refreshes thermostat state when Nuheat emits schedule notifications

## Upgrade Notes

- Existing `platform: "NuHeat"` configuration remains valid
- The new schedule switch feature is opt-in through `exposeScheduleSwitches`
- Package install name remains `homebridge-nuheat2`
