# 1.2.22 Release Notes

Released: 2026-07-07

## Summary

`1.2.22` updates the plugin for Nuheat's July 2026 Signature thermostat migration to the Conductor server architecture.

## Highlights

- Uses `identity.nam.mynuheat.com` for PKCE OAuth by default
- Uses `api.nam.mynuheat.com` for Nuheat REST API calls and SignalR notifications by default
- Centralizes Nuheat endpoint construction so future host changes are easier to handle
- Adds `NUHEAT_API_BASE_URL` and `NUHEAT_IDENTITY_BASE_URL` environment overrides for emergency troubleshooting
- Updates the README with the current Conductor/NAM API hosts

## Upgrade Notes

- Existing Homebridge configurations continue to work unchanged
- Restart Homebridge after installing so the plugin reconnects using the new Nuheat endpoints
