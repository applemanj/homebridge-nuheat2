# 1.2.6 Release Notes

Released: 2026-04-11

## Summary

`1.2.6` is a troubleshooting-focused patch release to make Nuheat API failures easier to diagnose in live Homebridge installs.

## Highlights

- Added `enableNotifications` so SignalR can be disabled while testing REST-only behavior
- Improved API error logging to show the failing request and a short response snippet
- Stopped making group API calls unless away-mode groups are actually configured

## Upgrade Notes

- No existing configuration needs to change unless you want to disable notifications while debugging
- To troubleshoot API issues, set `enableNotifications` to `false` and leave `groups` unset unless you use away-mode switches
