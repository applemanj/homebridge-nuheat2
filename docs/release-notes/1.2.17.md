# 1.2.17 Release Notes

Released: 2026-04-29

## Summary

`1.2.17` fixes a stale Advanced OAuth configuration edge case discovered while testing the new Nuheat PKCE public-client flow.

## Highlights

- Forces PKCE when the saved client ID is the built-in public client ID, `homebridge-nuheat2_260421`
- Ignores stale saved client secrets for the built-in public client
- Normalizes the Homebridge custom UI so entering the built-in public client ID behaves the same as leaving Advanced OAuth blank
- Adds regression coverage for the explicit built-in client ID plus stale secret case

## Upgrade Notes

- No configuration changes are required for most users
- If Advanced OAuth contains `homebridge-nuheat2_260421`, the plugin now treats it as the built-in PKCE public client
- Leaving Advanced OAuth fields blank remains the recommended configuration
