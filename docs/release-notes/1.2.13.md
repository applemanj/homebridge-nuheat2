# 1.2.13 Release Notes

Released: 2026-04-24

## Summary

`1.2.13` is an admin UI and configuration polish release. It adds a custom Homebridge settings experience aligned with the shared Roborock plugin design system, keeps every setting documented in `config.schema.json` and the README, and tightens notification and polling behavior.

## Highlights

- Adds a custom Homebridge admin UI with Account, Accessories, Behavior, Advanced OAuth, and Diagnostics panels
- Uses the shared design system from the Roborock plugin UI: CSS variables, readable panels, settings grids, status pills, and toast feedback
- Keeps saved passwords and legacy client secrets hidden while allowing users to replace or preserve them safely
- Documents all UI-backed settings in both `config.schema.json` and the README
- Clarifies that current custom OAuth overrides require both `clientId` and `clientSecret` until PKCE public-client support is implemented
- Subscribes to Nuheat schedule notifications and improves notification de-duplication bookkeeping
- Enforces a 30-second minimum polling interval at runtime to reduce accidental API load
- Removes an unused Homebridge UI utility dependency from the published package

## Upgrade Notes

- Existing `platform: "NuHeat"` configurations continue to work
- No manual config migration is required
- The new custom settings UI is included in the published package under `homebridge-ui`
- If using custom Nuheat OAuth credentials, keep `clientSecret` private and configure it only in your local Homebridge settings
