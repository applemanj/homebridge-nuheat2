# 1.2.14 Release Notes

Released: 2026-04-27

## Summary

`1.2.14` improves Homebridge theme compatibility for the custom Nuheat admin UI.

## Highlights

- Lets the main custom UI inherit Homebridge modal background and text colors
- Replaces hard-coded dark panels, text, inputs, and button styling with theme-aware CSS
- Keeps subtle custom styling for Nuheat-specific widgets such as allow-list panels, diagnostics cards, status pills, and fallback toasts
- Uses semantic plugin CSS variables and translucent borders/surfaces so the UI remains readable in both light and dark Homebridge themes

## Upgrade Notes

- No configuration changes are required
- Existing `platform: "NuHeat"` configurations continue to work
- This release only changes the custom Homebridge settings UI styling
