# 1.2.24 Release Notes

Released: 2026-07-08

## Summary

`1.2.24` restores Nuheat SignalR notifications after the Conductor/NAM migration.

## Highlights

- Uses Nuheat's documented v2 notification hub at `/v2/notificationsHost`
- Subscribes with numeric v2 notification IDs accepted by the new hub
- Uses direct WebSocket transport to avoid flaky negotiated SignalR connections behind the new backend
- Documents the notification host and `NUHEAT_NOTIFICATION_HUB_URL` emergency override

## Upgrade Notes

- Existing Homebridge configurations continue to work unchanged
- Polling remains enabled as the reliability fallback even when notifications are active
- Restart Homebridge after installing so the notification listener reconnects to the v2 hub
