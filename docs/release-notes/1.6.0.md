# 1.6.0 Release Notes

Released: 2026-11-24

## Summary

`1.6.0` adds optional per-thermostat Away switches and restores Hold Length `0` as "hold until the next scheduled event", both changes shaped by community feedback on issue #2.

## Highlights

- **Added: per-thermostat Away switches.** Enable `exposeAwaySwitches` to get a switch next to each thermostat. On, the thermostat is held permanently at `awaySetPointTempC` (default `10 °C`, configurable 5–30) — the floor keeps heating to that temperature, so the home stays protected from freezing. Off, the schedule resumes. This is a client-side permanent hold, independent of Nuheat's server-side group away mode
- **Changed: Hold Length `0` means "hold until the next scheduled event" again.** `0` writes Nuheat's schedule mode `AUTO` with the setpoint, exactly as requested in issue feedback. Negative values are still refused at startup with a logged warning; the config UI schema minimum is back to `0`

## Upgrade Notes

- No action needed for existing installations — both features are opt-in (`exposeAwaySwitches`) or restore prior behavior (Hold Length `0`)
- To try the Away switches, enable `exposeAwaySwitches` (and optionally set `awaySetPointTempC`) and restart Homebridge
- If you previously set Hold Length to `0` expecting "hold until the next scheduled event", that behavior is back
