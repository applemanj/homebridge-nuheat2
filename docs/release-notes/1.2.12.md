# 1.2.12 Release Notes

Released: 2026-04-21

## Summary

`1.2.12` is a thermostat behavior and notification polish release. It makes the Nuheat accessory present itself more honestly as a heat-only thermostat in HomeKit, fixes the displayed hardware unit to match the Nuheat account preference, and reduces duplicate refreshes triggered by repeated notifications.

## Highlights

- Restricts the thermostat target mode to `Heat` so HomeKit no longer offers a misleading off mode for Nuheat devices
- Converts any incoming off request into the minimum Nuheat target temperature instead of snapping back after the next refresh
- Sets `TemperatureDisplayUnits` from the Nuheat account temperature scale so HomeKit shows the correct hardware display unit
- Coalesces and briefly de-duplicates repeated SignalR notifications before refreshing thermostats or groups
- Adds regression coverage for the heat-only target mode, off-request translation, display-unit mapping, and notification de-duplication

## Upgrade Notes

- No configuration changes are required
- Existing `platform: "NuHeat"` configurations continue to work
- If HomeKit still shows the old thermostat mode options after upgrading, restart Homebridge and reopen the Home app so the characteristic metadata refreshes
