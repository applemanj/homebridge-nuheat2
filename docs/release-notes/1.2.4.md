# 1.2.4 Release Notes

Released: 2026-04-11

## Summary

`1.2.4` is the first stable release of the maintained `homebridge-nuheat2` fork. It combines the earlier beta work into a standard release focused on modernization, stability, and better alignment with Nuheat's published API.

## Highlights

- Fixed the thermostat manual-mode behavior that could cause HomeKit to switch back to `Off`
- Improved cached accessory startup behavior for modern Homebridge versions
- Added configurable Nuheat OAuth credentials while preserving current fallback behavior
- Improved SignalR connection handling and token refresh behavior
- Added regression tests for thermostat, model-normalization, and schedule-switch behavior
- Added optional per-thermostat schedule switches
- Added Swagger-aligned helpers for account, thermostat, schedule, group, and energy models
- Published under the maintainer-owned npm package name `homebridge-nuheat2`

## Upgrade Notes

- Existing `platform: "NuHeat"` configuration remains valid
- The npm install name is `homebridge-nuheat2`
- The new schedule switch feature is opt-in through `exposeScheduleSwitches`
- Developers should prefer their own `clientId` and `clientSecret` once Nuheat issues official API credentials
