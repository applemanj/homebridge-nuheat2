# 1.2.16 Release Notes

Released: 2026-04-29

## Summary

`1.2.16` switches the built-in Nuheat OAuth path to the vendor-approved Authorization Code with PKCE public-client flow.

## Highlights

- Uses the public Nuheat client ID `homebridge-nuheat2_260421` by default
- Removes the need to ship or configure a distributable Nuheat client secret
- Keeps custom legacy confidential-client overrides available for alternate Nuheat-issued test clients
- Updates the Homebridge settings UI, README, and schema copy to explain the PKCE flow
- Adds automated coverage for PKCE challenge generation, token requests, and legacy OAuth fallback behavior

## Upgrade Notes

- No configuration changes are required for normal use
- Leave Advanced OAuth fields blank unless Nuheat issued alternate credentials for testing
- Existing `platform: "NuHeat"` configurations continue to work
