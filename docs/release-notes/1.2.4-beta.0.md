# 1.2.4-beta.0 Release Notes

Released: 2026-04-11

## Summary

`1.2.4-beta.0` is a modernization release for the Nuheat Homebridge plugin fork. It focuses on stability, compatibility, and release readiness rather than broad feature expansion.

## Highlights

- Fixed the thermostat manual-mode behavior that could cause HomeKit to switch back to `Off`
- Improved cached accessory startup behavior for modern Homebridge versions
- Added configurable Nuheat OAuth credentials while preserving current fallback behavior
- Improved SignalR connection handling and token refresh behavior
- Added regression tests for the most important thermostat fixes
- Updated package metadata for Homebridge 1.8+ and 2.0 beta compatibility
- Published under the new maintainer-owned npm package name `homebridge-nuheat2`

## Technical Changes

- Startup now waits for Homebridge `didFinishLaunching` before accessory discovery
- Notification connections now use an access-token factory instead of a static token
- Transitive `ws` and `tough-cookie` dependencies are pinned to non-vulnerable versions through npm overrides
- The plugin now documents and exposes advanced OAuth overrides in both config schema and README

## Upgrade Notes

- Existing `platform: "NuHeat"` configurations remain valid
- The npm install name for this fork is now `homebridge-nuheat2`
- Existing user credentials continue to work the same way
- Users testing Homebridge 2.0 should run on Node 22 or 24
- Developers planning a long-term deployment should request an official Nuheat client ID and client secret

## Known Follow-Up Work

- Validate the plugin against an official Nuheat API client registration
- Reconfirm group/away-mode behavior against live API responses
- Decide on the npm package identity if publishing under a new maintainer-owned package becomes necessary
