# 1.2.19 Release Notes

Released: 2026-04-30

## Summary

`1.2.19` fixes a custom admin UI readability issue in the Accessories allow-list editor.

## Highlights

- Makes saved thermostat and group allow-list values readable inside editable inputs
- Gives each allow-list row more room by placing actions below the value field
- Keeps the Homebridge theme-compatible translucent control styling

## Upgrade Notes

- No configuration changes are required
- Existing thermostat and group allow-list entries remain supported
